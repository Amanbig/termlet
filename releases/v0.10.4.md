# Termlet v0.10.4 🚀

Termlet **v0.10.4** is a maintenance and stability release updating core dependencies from Dependabot, including **`marked`** (`18.2.1`) for robust markdown rendering and **`lucide-react`** (`1.78.0`) for extended iconography, alongside general performance and stability polish.

---

### ✨ What's New & Highlights

#### 📦 Core Dependency Updates (Dependabot)
- **`marked` (18.2.0 &rarr; 18.2.1)**:
  - Upgraded markdown parser with security fixes and improved GFM tables and link parsing reliability in the in-app release notes viewer.
- **`lucide-react` (1.75.0 &rarr; 1.78.0)**:
  - Expanded icon library with performance improvements and the latest UI icons.

#### 🛡️ Stability & Polish
- Validated clean production builds and comprehensive test suite across Go backend and Vite/TypeScript frontend.
- Clean inter-process communication handling with the latest package ecosystem.
